### Rust Quick Start Guide

Краткая шпаргалка по созданию, запуску и компиляции проектов на Rust. 

### Работа с проектами (Cargo)

### Создание нового проекта

bash

cargo new my_project

Используйте код с осторожностью.

### Переход в папку проекта

bash

cd project_path

Используйте код с осторожностью.

### Запуск проекта из его директории

bash

cargo run

Используйте код с осторожностью.

### Запуск проекта из другой директории

Если вы находитесь вне папки проекта, укажите путь к файлу конфигурации: 

bash

cargo run --manifest-path="path_to_Cargo.toml"

Используйте код с осторожностью.

### Компиляция одиночного файла

Если у вас нет полноценного проекта Cargo, а есть только один файл формата .rs, используйте этот метод: 

bash

# Компиляция файла
rustc main.rs

# Или с указанием полного пути:
rustc "path_to_file_RS_type"

# Запуск скомпилированного файла (в Windows)
.\main.exe

Используйте код с осторожностью.
